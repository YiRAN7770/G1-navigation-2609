# site04 Z-up：俯视逆时针90°版本

2026-09-23，按用户“从天花板向下看仍需逆时针旋转90°”的要求生成。

- 来源：历史 Z-up 地图；源目录未随本发布包提供。
- 旋转中心：地图原点；绕 Z 朝上轴 +90°。
- 相对旧 zup：`(x,y,z) → (-y,x,z)`；初始朝向及目标朝向 `yaw_new=wrap(yaw_old+π/2)`。
- 相对最初 Z 朝下地图的组合变换：`(x,y,z) → (y,x,-z)`，行列式为 +1，是正规旋转而非镜像。
- 点云720693点，完整VGH1350节点，精简VGH429节点；节点ID、语义标记和所有连接关系保持不变。
- PCD法线、VIEWPOINT和VGH表面方向同步旋转；Z和距离不变。

定位使用 `prior.pcd`，读图使用同目录 `site_04_compact_trajectory.vgh`，保持 `lidar_inverted:=true`、`route_planner_config:=site04_zup`。初始化及目标应在新图中重新选择；定位器据此将实时点云和位姿映射到新地图，不在其后再加一次90°点云旋转。

本目录没有二维栅格图。不要将原始地图目录中的 PGM/YAML 当作这个版本的配套栅格；FAR 本流程使用 PCD/VGH。

验证：720693点及法线逐点旋转误差为0，Z、强度和曲率不变；两份VGH的全部连接和语义标记保留。使用新地图及同步旋转的初始位姿，site04旧录包定位回放 ready=true，与旋转后的录包参考位姿位置差约0.005 m、yaw差约0.162°；这是离线复现一致性，不是现场绝对精度。原始运行日志未随仓库发布。

生成工具：`tools/rotate_site04_zup_ccw90.py`。哈希、旋转矩阵和来源见 `conversion.json`。文件生成不代表现场已验证重合；发布包只提供已生成的地图资产。
